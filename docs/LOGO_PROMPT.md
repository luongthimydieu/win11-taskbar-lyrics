# Logo 生成提示词（给 GPT / DALL·E / 其他绘图模型）

> 本项目已生成并内置正式 Logo（磨砂玻璃音乐清单图标）：
> `desktop/logo_source.png`（原图）、`desktop/logo.png`（去白底 1024 透明）、`desktop/logo.ico`（exe 图标）；
> 手机端 PWA 图标（`github-pages/icon-192.png` / `icon-512.png` / `apple-touch-icon.png`）也已由它生成。
> 下面的提示词留作以后换风格时参考。

项目定位：**Win11 任务栏歌词 + 网易云精选热评 + 手机端跨端待办**。视觉关键词建议：
深色、科技感、音乐、任务栏、待办勾选、蓝色高光、简洁矢量、小尺寸可辨识。

> 小技巧：要求 GPT 输出“1024×1024 正方形、纯色背景（不要透明）、不要文字、图标居中、四周留白约 10%”。
> 拿到图后可以自己抠背景，或用 `tools/make_ico.py`（本仓库附带）转成 Windows `.ico`。

---

## 提示词 A：应用图标（推荐先做这个，1:1）

```text
请设计一个 Windows 11 桌面应用的 App 图标，1024x1024 正方形，扁平化矢量风格，深色科技感。

主题：任务栏歌词 + 音乐 + 待办清单。
画面构成（居中、简洁、不超过 3 个视觉元素）：
1) 一个圆角方块底座，深海军蓝到近黑的细腻渐变（#0F172A → #020617），带非常轻微的玻璃质感高光；
2) 正中间是一个简洁的白色/青色（#38BDF8）音符，或一条“歌词字幕条”造型（横向细条 + 文字占位线）；
3) 右下角有一个小小的绿色（#34D399）圆形勾选徽标，表示“待办完成”；
4) 可选：底部一条极简的“任务栏”横条元素，暗示组件贴在任务栏上。

风格要求：
- 扁平矢量、干净利落、几何化、无照片感、无 3D 写实、无复杂纹理；
- 深色背景 + 青色高光，高对比度，缩小到 32x32 仍能看清轮廓；
- 不要出现任何文字、字母、数字、水印、边框；
- 图标主体占画面约 70%，四周留白均匀；
- 纯色背景不要透明，方便后期抠图。

输出：1024x1024 PNG，正方形，居中构图。
```

## 提示词 B：带名称的 Logo（横版，用于 README 首图 / 启动页）

```text
请设计一个软件 Logo 横版组合：左侧图形标志 + 右侧中文字标，比例 4:1，深色背景，扁平矢量风格。

文字内容（必须准确、简洁）："任务栏歌词待办"
左侧图形：深海军蓝圆角方块（#0F172A）内嵌一个青色音符（#38BDF8）和一条细横线（象征任务栏与歌词条），右下角一个小绿色勾选（#34D399）；
右侧字标：白色、现代无衬线中文字体，字重中等，字距舒展；副标题一行小字 "Taskbar Lyrics · Todo"（可选，浅灰色）。

要求：
- 背景透明或纯深色（#0B1220），无杂乱装饰、无 3D、无描边光效过重；
- 横版构图，左右留白均衡，适合放在 GitHub README 顶部；
- 中文必须正确，不要出现错别字或乱码；不确定中文时宁可只保留图形标志。

输出：1600x400 PNG。
```

## 提示词 C：README 顶部 Banner（宽图，氛围向）

```text
请设计一张 GitHub 项目 README 顶部 Banner，宽高比 16:5（如 1600x500），深色科技感插画风。

画面：一台 Windows 11 笔记本的局部（屏幕底部任务栏区域），任务栏左侧有一条半透明信息条，显示两行文字占位（第一行是音乐歌词，第二行是评论/待办），旁边有细小的青色波形和音符点缀；整体深蓝黑背景 + 青色霓虹高光，扁平插画、干净、无真实人物、无厂商 Logo。

要求：不要出现真实文字（用抽象色块/占位条表示）、无写实照片、无复杂噪点；留出上方/左侧空白方便叠加项目名。
输出：1600x500 PNG。
```

## 拿到图之后怎么用

1. **App 图标 / exe 图标**：把图保存为 `desktop/logo.png`（1024×1024），然后在本仓库运行：

   ```bat
   python tools\make_ico.py desktop\logo.png desktop\logo.ico
   ```

   得到 `desktop/logo.ico`；打包时执行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File desktop\build_exe.ps1 -Icon desktop\logo.ico
   ```

2. **替换 PWA 图标**：把 1024 图另存为 `github-pages/logo-source.png`，运行 `python tools\make_icons.py --source github-pages\logo-source.png`（该脚本会生成 192/512/apple-touch 三张图），然后重新 push `github-pages` 仓库。

3. **README Banner**：把 Banner 放 `docs/assets/banner.png`，在 README 顶部加：

   ```markdown
   ![任务栏歌词待办](docs/assets/banner.png)
   ```
