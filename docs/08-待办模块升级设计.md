# 08 待办模块升级设计（v1.3.0 契约）

> 注：v1.3.2 已把每日记忆改为 **04:00 推送前一天**，并新增「AI 只在空闲时段调用」（`ai_idle_only/ai_idle_minutes/ai_idle_start/ai_idle_end`）与 `memory_time` 默认 `04:00`；本文其余契约不变。

本文是 v1.3.0「待办 + 记账 + 周报 + 每日记忆」的模块契约。并行开发时以本文件为准，**不要改不属于自己范围的写作用域**。

## 0. 目标与边界

1. 待办支持**目标完成日期**（`due_date`），可指定未来某天完成；
2. 复杂任务可拆成多个**子任务**（`parent_id` 指向父任务），桌面端可调用 OpenAI 兼容大模型 API 规划拆解与日期；
3. 新增**记账**：每日收入/支出，分类、备注，按周汇总；
4. 每周自动发**邮件周报**（Gmail SMTP）：本周完成/未完成/待改进 + 账单汇总 + AI 评价；
5. 每日定时把**记忆**（完成情况、账单、AI 评价）推送到私有仓库 `luongthimydieu/taskbar-memory`（已创建）；
6. 手机 PWA 为主录入（待办目标日期、记账），桌面右键辅助；桌面仍只显示“下一项”。

## 1. 待办文档 schema v3（`desktop/core.py`）

在现有 schema 2 的 todo 字段基础上新增 3 个字段（旧数据缺失时默认 `""` / `0`）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `due_date` | `"YYYY-MM-DD"` 或 `""` | 目标完成日期；空=未指定 |
| `parent_id` | `str` | 父任务 id；空=独立任务 |
| `estimate_minutes` | `int >= 0` | 预计耗时（分钟），0=未估 |

要求：

- `normalize_todo` 补齐/校验上述字段；`add_todo(..., due_date="", parent_id="", estimate_minutes=0)`；`update_todo` 白名单加入字段；
- 文档 `schema` 升到 **3**（`SCHEMA_VERSION = 3`）；`normalize_doc` 输出带这 3 个键，**canonical 的键排序与前端严格一致**；
- 归属日期：`todo_day(todo)` 优先用 `due_date`（合法时），否则沿用原 created_at 规则；
- 新增查询：`subtasks(doc, parent_id)`、`parent_progress(doc, parent_id) -> (done,total)`、`upcoming_todos(doc, start_day, days=14)`；
- `format_todo_line`：父任务显示 `[done/total]`；有 due_date 时显示 `📅 今天/明天/MM-DD`；逾期显示「逾期」；
- 周报数据：`weekly_report_data(doc, ledger, week_start: date) -> dict`，包含：
  `week_start/week_end`、`completed`（本周 done_at 的 todo）、`pending`（未完成）、`overdue`（due_date < today 未完成）、`created`（本周创建）、`subtask_progress`、`improvements`（规则生成的改进建议 list[str]）、`ledger`（见下）；
- 周报渲染：`weekly_report_markdown(data, ai_comment="") -> str`。

## 2. 记账（独立 Gist，`taskbar_ledger.json`）

文档结构（schema 1）：

```json
{
  "schema": 1,
  "version": 0,
  "updated_at": "ISO8601",
  "entries": [
    {"id": "lg-...", "date": "2026-10-20", "type": "income|expense",
     "amount": 12.5, "category": "餐饮", "note": "", "created_at": "ISO", "updated_at": "ISO"}
  ],
  "tombstones": [{"id": "lg-...", "deleted_at": "ISO"}]
}
```

core 需提供：

- `empty_ledger()`, `normalize_ledger(raw)`, `canonical_ledger(doc)`, `merge_ledgers(a,b)`；
- `add_ledger_entry(doc, date, type, amount, category, note="", entry_id=None) -> (doc, entry)`；
- `update_ledger_entry`, `delete_ledger_entry`；
- `ledger_week_summary(doc, week_start) -> dict`：`income`, `expense`, `net`, `by_category`: `{category: {income, expense}}`, `entries`（本周按日期排序）；
- `format_money(value) -> "¥12.50"`；
- `LedgerStore(token, gist_id, filename="taskbar_ledger.json", timeout=8)`：接口参考 `GitHubGistStore`：`configured`、`sync(local, etag) -> report`、`create_gist(doc) -> gist_id`、`fetch()`；网络/API 错误抛 `GitHubApiError`；
- 测试覆盖：归一化、合并、周汇总、canonical 稳定性、CRUD。

## 4. 集成模块（新增文件）

### `desktop/ai_client.py`

- `class OpenAICompatibleClient(base_url, api_key, model, timeout=40)`：`chat(messages, temperature=0.3, json_mode=False) -> str`，POST `{base_url}/chat/completions`，支持 `response_format={"type":"json_object"}`；
- `plan_complex_task(client, task_text, today, horizon_days=14) -> dict`：
  `{"title": str, "steps":[{"text": str, "due_date": "YYYY-MM-DD", "estimate_minutes": int}], "note": str}`；
  尽量让模型输出 JSON；解析失败/日期越界时抛 `PlanError`；
- `evaluate(kind, client, context) -> str`：kind=`"day"`/`"week"`，返回 2–5 句中文评价与 1 条改进建议；
- 无 API key / 网络失败：调用方降级（不阻塞主功能）。

### `desktop/reporting.py`

- `send_email(config, subject, html, text="")`：`smtplib.SMTP_SSL(host, port, timeout=30)`；配置键 `mail_host` 默认 `smtp.gmail.com`、`mail_port` 465、`mail_user`、`mail_password`、`mail_to`；失败抛 `MailError`；
- `build_weekly_email(report_data, ai_comment="") -> (subject, html, text)`：中文 HTML，含完成/未完成/逾期/改进建议/账单明细；
- `format_week_range(week_start)`。

### `desktop/memory_sync.py`

- `class MemoryRepo(token, repo="luongthimydieu/taskbar-memory", branch="main", timeout=30)`：
  - `ensure_repo()`：GET repo；404 时 POST `/user/repos` 创建私有仓库（auto_init）；
  - `put_file(path, content, message) -> html_url`：GET 现有 sha → PUT contents（新建/更新）；
  - `get_file(path) -> str|None`；
- `build_daily_memory(doc, ledger, moment, ai_comment="") -> markdown`：日期、今日完成、未完成/逾期、今日账单、AI 评价；
- `push_daily_memory(config, doc, ledger, moment, ai_comment)`：写 `memories/YYYY-MM-DD.md` + 更新 `memories/index.json`（数组，按日期倒序，最多 400 条）；
- 配置键：`memory_repo`、`memory_token`、`memory_enabled`、`memory_time`（"23:30"）、`memory_branch`；
- 测试用假 session/requests mock，不能真的发网络请求。

## 5. 桌面端（`desktop/taskbar_widget.py`，Lead 负责）

新增配置键（`DEFAULT_CONFIG`）：

```json
"ai_enabled": true, "ai_base_url": "https://api.deepseek.com", "ai_api_key": "", "ai_model": "deepseek-chat",
"mail_host": "smtp.gmail.com", "mail_port": 465, "mail_user": "", "mail_password": "", "mail_to": "",
"ledger_gist_id": "",
"memory_enabled": true, "memory_repo": "luongthimydieu/taskbar-memory", "memory_token": "",
"memory_time": "23:30", "weekly_report_enabled": true, "weekly_report_weekday": 7,
"weekly_report_time": "21:00", "last_memory_date": "", "last_report_week": ""
```

功能：

- 右键菜单：➕ 添加待办（目标日期/优先级/AI 拆解）、🤖 AI 拆解复杂任务、💰 记一笔、📒 本周账单、📊 周报预览、📤 立即发送周报、🧠 立即推送今日记忆；设置对话框增加 AI / Gmail / 记忆仓库 / 账本 Gist 配置；
- 定时器每 30 秒检查 `memory_time`/`weekly_report_time`，到点后台线程执行、state 去重；
- 任务栏文案展示父任务进度与 due_date；
- 账本 Gist 同步（每 30 秒，参考现有 Gist sync）；
- 失败只托盘提示，不阻塞主 UI。
